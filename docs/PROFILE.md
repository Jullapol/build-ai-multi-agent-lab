## Bio
สวัสดีครับ ผม JT — Builder ที่เชื่อว่างานควรเสร็จเร็ว เพื่อให้เรามีเวลาไปนอนเล่นมากขึ้น (นี่คือเป้าหมายหลัก ไม่ได้พูดเล่น)

ทุกอย่างเริ่มจากคำถามง่าย ๆ: "จะมีผู้ช่วยสักคนได้ไหม แบบไม่ต้องจ่ายเงินเดือน" คำตอบคือทีม AI agents ที่แบ่งหน้าที่กันชัด ๆ — ตัวหนึ่งจดงาน ตัวหนึ่งเช็กงาน อีกตัวคอยสะกิดว่า "ลืมอะไรรึเปล่า" เหมือนมีเลขาส่วนตัว แต่ไม่ต้องเลี้ยงกาแฟ

อีกงานที่ agent ช่วยได้เยอะคือไล่ process flow ที่ไม่มีใครเขียนเอกสารไว้ แล้ว debug จนเจอว่าบั๊กซ่อนอยู่ตรงไหน — แทนที่จะนั่งเดาทั้งคืน ก็ให้ agent ช่วยวาดแผนที่ แล้วเราค่อยเดินตาม

สิ่งที่ผมเรียนรู้คือ multi-agent ไม่ใช่เวทมนตร์ มันคือการแบ่งงานให้ชัด ใครทำอะไร ส่งต่อกันยังไง และรู้ว่าเมื่อไหร่ควรหยุด — เหมือนทีมคนจริง ๆ นั่นแหละ แค่ไม่ต้องประชุมยาว

เว็บนี้คือที่ผมเล่าว่าทำยังไงให้ multi-agent ทำงานได้จริง ไม่ใช่แค่เดโมสวย ๆ — ถ้าคุณอยากทำงานน้อยลงแต่ได้ผลเท่าเดิม (หรือดีกว่า) และกลับบ้านตรงเวลาบ่อยขึ้น ยินดีต้อนรับครับ

## Audience
คนทำงานทั่วไปที่อยากใช้ AI เป็นผู้ช่วย ให้งานเสร็จเร็วขึ้นและมีเวลาพักมากขึ้น — ไม่ต้องเป็นสาย tech ก็อ่านรู้เรื่อง

## Interests
- ระบบ multi-agent / AI agents — ทำยังไงให้ AI หลายตัวทำงานเป็นทีม ไม่ใช่ต่างคนต่างมั่ว
- AI เป็นผู้ช่วย / เลขาส่วนตัว — ให้ AI ช่วยจด เตือน สรุป แทนเรา
- ไล่ process flow และ debug โค้ดที่รับต่อจากคนอื่น — เปลี่ยนโค้ดลึกลับให้เป็นแผนที่ที่อ่านออก
- เทคนิคทำงานให้เร็วขึ้น (productivity) — ทำน้อยลง ได้เท่าเดิม แล้วเอาเวลาที่เหลือไปพัก
